# Stochastic Optimization Algorithms

My solutions to the programming assignments in **FFR105 Stochastic Optimization Algorithms** at Chalmers University of Technology (autumn 2026). Course book: M. Wahde, *Biologically Inspired Optimization Methods*. Everything is written from scratch in Python.

| Folder | Algorithm | Problem |
|---|---|---|
| [`intro-newton-raphson`](intro-newton-raphson) | Newton–Raphson | Stationary points of a polynomial |
| [`hw1-penalty-method`](hw1-penalty-method) | Penalty method + gradient descent | Constrained minimisation |
| [`hw1-genetic-algorithm`](hw1-genetic-algorithm) | Genetic algorithm | Minimising a 2D test function |
| [`hw2-ant-system-tsp`](hw2-ant-system-tsp) | Ant System (ACO) | 50-city travelling salesman problem |
| [`hw2-particle-swarm-optimization`](hw2-particle-swarm-optimization) | Particle swarm optimization | Himmelblau's function |

## Running

```bash
pip install numpy matplotlib
cd <folder>
python <script>.py
```
